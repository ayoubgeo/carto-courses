Ingesting and Preprocessing Multi-Sensor Climate Covariates
10 min

Paste the following code into your GEE code editor and click Run. Read the beginner notes below to understand what each line does.

Ingesting and Preprocessing Multi-Sensor Climate Covariates
var roi = ee.Geometry.Polygon([
  [[-120, 30], [-120, -30], [150, -30], [150, 30]]
], null, false);

var startDate = '2022-01-01';
var endDate = '2022-12-31';

var era5 = ee.ImageCollection('ECMWF/ERA5_LAND/MONTHLY_AGGR')
  .filterDate(startDate, endDate)
  .select('temperature_2m');
var meanAirTempC = era5.mean().subtract(273.15).rename('air_temp_c');

var modisLST = ee.ImageCollection('MODIS/061/MOD11A2')
  .filterDate(startDate, endDate)
  .select(['LST_Day_1km', 'LST_Night_1km']);
var meanLST = modisLST.mean().multiply(0.02).subtract(273.15).rename(['lst_day_c', 'lst_night_c']);

var chirps = ee.ImageCollection('UCSB-CHG/CHIRPS/PENTAD')
  .filterDate(startDate, endDate)
  .select('precipitation');
var totalPrecip = chirps.sum().rename('annual_precip_mm');

var predictorStack = meanAirTempC
  .addBands(meanLST.select('lst_day_c'))
  .addBands(totalPrecip)
  .clip(roi);

Map.centerObject(roi, 3);
Map.addLayer(predictorStack.select('air_temp_c'), {min: 10, max: 35, palette: ['blue', 'yellow', 'red']}, 'Mean Air Temp (C)');
Map.addLayer(predictorStack.select('annual_precip_mm'), {min: 100, max: 3000, palette: ['white', 'cyan', 'darkblue']}, 'Annual Precip (mm)');
🔑
Beginner note: This script defines a study region covering tropical and subtropical belts (-30 to +30 latitude). It extracts monthly mean air temperature from ERA5-Land, converts Kelvin to Celsius, calculates 8-day MODIS day land surface temperature, and sums pentad CHIRPS precipitation for 2022. The layers are combined into a single multi-band image stack for downstream environmental suitability modeling.

Machine Learning Suitability Modeling and Risk Stratification
10 min

Add this block after the previous code. It continues the analysis with additional processing and visualization.

Machine Learning Suitability Modeling and Risk Stratification
var tempSuitability = predictorStack.select('air_temp_c').gte(20).and(predictorStack.select('air_temp_c').lte(32));
var precipSuitability = predictorStack.select('annual_precip_mm').gte(500);
var pseudoSuitability = tempSuitability.and(precipSuitability).rename('suitability');

var presencePoints = pseudoSuitability.selfMask().stratifiedSample({
  numPoints: 400,
  classBand: 'suitability',
  region: roi,
  scale: 20000,
  geometries: true
}).map(function(f) { return f.set('label', 1); });

var absencePoints = pseudoSuitability.not().selfMask().stratifiedSample({
  numPoints: 400,
  classBand: 'suitability',
  region: roi,
  scale: 20000,
  geometries: true
}).map(function(f) { return f.set('label', 0); });

var trainingData = presencePoints.merge(absencePoints);

var trainingSamples = predictorStack.sampleRegions({
  collection: trainingData,
  properties: ['label'],
  scale: 20000,
  tileScale: 4
});

var classifier = ee.Classifier.smileRandomForest(100)
  .train({
    features: trainingSamples,
    classProperty: 'label',
    inputProperties: predictorStack.bandNames()
  });

var suitabilityMap = predictorStack.classify(classifier);

Map.addLayer(suitabilityMap, {min: 0, max: 1, palette: ['lightgray', 'orange', 'red']}, 'RF Environmental Suitability Proxy');
🔑
Beginner note: This script defines biological heuristic rules (temperatures between 20C and 32C and rainfall exceeding 500mm) to generate pseudo-presence and absence training locations. A Random Forest classifier with 100 decision trees is trained on the multi-sensor climate stack. The model classifies global environmental suitability into a continuous spatial indicator.
