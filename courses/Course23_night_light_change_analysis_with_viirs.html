VIIRS Collection Filtering, Noise Masking, and Annual Compositing
10 min

Paste the following code into your GEE code editor and click Run. Read the beginner notes below to understand what each line does.

VIIRS Collection Filtering, Noise Masking, and Annual Compositing
var viirs = ee.ImageCollection('NOAA/VIIRS/DNB/MONTHLY_V1/VCMSLCFG');
var countries = ee.FeatureCollection('USDOS/LSIB_SIMPLE/2017');

// Preprocessing function to filter cloud-free observations and background noise
function preprocessVIIRS(img) {
  var cloudFree = img.select('cf_cvg').gte(2);
  var radiance = img.select('avg_rad');
  // Mask out noise and low-quality pixels (< 0.5 nW/cm^2/sr)
  var maskedRadiance = radiance.updateMask(cloudFree).updateMask(radiance.gte(0.5));
  return img.addBands(maskedRadiance.rename('cleaned_rad'), null, true);
}

var processedCollection = viirs.map(preprocessVIIRS);

// Generate 2014 and 2023 annual medians
var median2014 = processedCollection.filterDate('2014-01-01', '2014-12-31')
                                    .select('cleaned_rad').median();
var median2023 = processedCollection.filterDate('2023-01-01', '2023-12-31')
                                    .select('cleaned_rad').median();

// Calculate absolute change
var absoluteChange = median2023.subtract(median2014).rename('radiance_change');

// Visualization parameters
var radVis = {min: 0.5, max: 30, palette: ['black', 'purple', 'cyan', 'lime', 'yellow', 'white']};
var diffVis = {min: -10, max: 10, palette: ['blue', 'black', 'red']};

Map.setCenter(15.0, 20.0, 3);
Map.addLayer(median2014, radVis, '2014 Night Lights Median');
Map.addLayer(median2023, radVis, '2023 Night Lights Median');
Map.addLayer(absoluteChange, diffVis, 'Radiance Change (2023 - 2014)');
🔑
Beginner note: This script loads the monthly stray light corrected VIIRS collection and applies quality control. The function screens out pixels with fewer than 2 cloud-free coverage days (cf_cvg) and removes background noise below 0.5 nW/cm^2/sr. Annual medians for 2014 and 2023 are generated to mitigate seasonal fluctuations, followed by a pixel difference calculation to reveal global light changes over a decade.

Time Series Trend Fitting and Machine Learning Classification
10 min

Add this block after the previous code. It continues the analysis with additional processing and visualization.

Time Series Trend Fitting and Machine Learning Classification
var processedCollection = ee.ImageCollection('NOAA/VIIRS/DNB/MONTHLY_V1/VCMSLCFG')
  .filterDate('2014-01-01', '2023-12-31')
  .map(function(img) {
    var date = img.date();
    var years = date.difference(ee.Date('2014-01-01'), 'year');
    var cleanRad = img.select('avg_rad').updateMask(img.select('cf_cvg').gte(2));
    return cleanRad.addBands(ee.Image.constant(years).rename('time'))
                   .addBands(ee.Image.constant(1).rename('constant'));
  });

// Calculate linear trend across time series
var linearFit = processedCollection.select(['time', 'avg_rad']).reduce(ee.Reducer.linearFit());
var slope = linearFit.select('scale').rename('annual_slope');

// Define sample predictor metrics for Random Forest
var meanRad = processedCollection.select('avg_rad').mean().rename('mean_rad');
var maxRad = processedCollection.select('avg_rad').max().rename('max_rad');
var features = ee.Image.cat([meanRad, maxRad, slope]);

// Unsupervised KMeans clustering as target generator for ML training
var clusterer = ee.Clusterer.wekaKMeans(4).train({
  features: features.sample({region: Map.getBounds(true), scale: 5000, numPixels: 1000})
});
var clusters = features.cluster(clusterer);

// Visualization parameters
var slopeVis = {min: -0.5, max: 0.5, palette: ['darkblue', 'blue', 'white', 'orange', 'red']};
Map.addLayer(slope, slopeVis, '10-Year Linear Slope (nW/cm^2/sr/yr)');
Map.addLayer(clusters.randomVisualizer(), {}, 'Light Trajectory Clusters');
🔑
Beginner note: This block implements pixel-wise linear regression over a 10-year VIIRS time series (2014-2023). It calculates a temporal scale band representing annual change rates. It then combines summary metrics (mean, max, slope) into a multi-band predictor image and applies spatial clustering to categorize global light change trajectories automatically.

Export to Google Drive

Export.image.toDrive({

  description: 'VIIRS_Nightlight_Linear_Slope_Global',
