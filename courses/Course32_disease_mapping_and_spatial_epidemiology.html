Multi-Source Data Loading, Harmonization, and Feature Generation
10 min

Paste the following code into your GEE code editor and click Run. Read the beginner notes below to understand what each line does.

Multi-Source Data Loading, Harmonization, and Feature Generation
// Define study bounding box for sample regional analysis
var roi = ee.Geometry.Polygon([[
  [-82.0, -18.0], [-82.0, 12.0], [-34.0, 12.0], [-34.0, -18.0]
]], null, false);

// Filter ERA5-Land Monthly Climate Data for 2022
var era5 = ee.ImageCollection('ECMWF/ERA5_LAND/MONTHLY_AGGR')
  .filterDate('2022-01-01', '2022-12-31')
  .filterBounds(roi);

// Calculate mean temperature (convert Kelvin to Celsius) and total annual precipitation
var meanTemp = era5.select('temperature_2m_mean')
  .mean()
  .subtract(273.15)
  .rename('mean_temp_c');

var totalPrecip = era5.select('total_precipitation_sum')
  .sum()
  .multiply(1000)
  .rename('total_precip_mm');

// Load MODIS 16-Day NDVI for 2022 and compute annual mean
var modisNdvi = ee.ImageCollection('MODIS/061/MOD13A2')
  .filterDate('2022-01-01', '2022-12-31')
  .select('NDVI')
  .mean()
  .multiply(0.0001)
  .rename('mean_ndvi');

// Load WorldPop 2020 Global Population Grid
var population = ee.ImageCollection('WORLDPOP/GP/100m/pop')
  .filterDate('2020-01-01', '2020-12-31')
  .mosaic()
  .rename('population_count');

// Concatenate environmental predictor variables into a single multi-band image
var predictors = ee.Image.cat([meanTemp, totalPrecip, modisNdvi]).clip(roi);

// Set Map visualization settings
Map.centerObject(roi, 4);
Map.addLayer(meanTemp, {min: 15, max: 35, palette: ['blue', 'yellow', 'red']}, 'Mean Temp (C)');
Map.addLayer(totalPrecip, {min: 0, max: 3000, palette: ['white', 'blue', 'darkblue']}, 'Precipitation (mm)');
Map.addLayer(modisNdvi, {min: 0, max: 0.8, palette: ['brown', 'yellow', 'green']}, 'Mean NDVI');
🔑
Beginner note: This block harmonizes atmospheric parameters from ERA5-Land, vegetation dynamics from MODIS, and demographic data from WorldPop over a tropical study area. Temperature is converted from Kelvin to Celsius and precipitation is accumulated to annual totals. All predictor bands are stacked into a multi-band image layer ready for spatial model training.

GeoAI Random Forest Classifier and Population Exposure Analysis
10 min

Add this block after the previous code. It continues the analysis with additional processing and visualization.

GeoAI Random Forest Classifier and Population Exposure Analysis
// Generate pseudo-presence and absence sampling locations for suitability training
// Note: Real disease incidence or vector presence coordinates should be imported securely
var presencePoints = ee.FeatureCollection.randomPoints(roi, 100, 42)
  .map(function(f) { return f.set('class', 1); });
var absencePoints = ee.FeatureCollection.randomPoints(roi, 100, 99)
  .map(function(f) { return f.set('class', 0); });

var trainingSample = presencePoints.merge(absencePoints);

// Sample spatial covariates at point locations
var trainingData = predictors.sampleRegions({
  collection: trainingSample,
  properties: ['class'],
  scale: 1000,
  geometries: false
});

// Train Random Forest classifier for vector niche modeling
var classifier = ee.Classifier.smileRandomForest(50).train({
  features: trainingData,
  classProperty: 'class',
  inputProperties: ['mean_temp_c', 'total_precip_mm', 'mean_ndvi']
});

// Predict spatial environmental suitability
var suitabilityMap = predictors.classify(classifier).rename('suitability');

// Overlay suitability prediction with WorldPop to isolate exposed population
var highRiskPop = population.updateMask(suitabilityMap.eq(1)).clip(roi);

// Visualization
Map.addLayer(suitabilityMap, {min: 0, max: 1, palette: ['lightgray', 'darkred']}, 'Predicted Risk Class');
Map.addLayer(highRiskPop, {min: 0, max: 500, palette: ['yellow', 'orange', 'purple']}, 'Exposed Population Density');

// Calculate total exposed population across the region
var totalExposed = highRiskPop.reduceRegion({
  reducer: ee.Reducer.sum(),
  geometry: roi,
  scale: 1000,
  maxPixels: 1e9
});
print('Estimated High-Risk Exposed Population:', totalExposed);
🔑
Beginner note: In this block, we train a Random Forest classifier using sampled environmental variables corresponding to vector presence and absence proxies. The output classifies ecological suitability across the region. We then mask high-resolution WorldPop demographic counts to calculate the total exposed population residing within high-suitability zones.

Export to Google Drive
// Export the continuous predicted disease suitability map to Google Drive
Export.image.toDrive({
  image: suitabilityMap,
  description: 'Vector_Disease_Suitability_Map_2022',
  folder: 'GEE_Spatial_Epidemiology',
  fileNamePrefix: 'suitability_risk_map_1km',
  region: roi,
  scale: 1000,
  maxPixels: 1e9,
  crs: 'EPSG:4326'
});
🔑
Beginner note -- Export.image.toDrive(): This function does not export immediately. It creates a task in the GEE Tasks tab that you must manually start by clicking Run. The file will appear in your Google Drive folder (GEE_Courses) as a GeoTIFF that you can open in QGIS or ArcGIS.
